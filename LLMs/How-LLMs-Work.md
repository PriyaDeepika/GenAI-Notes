# What is a LLM?

<br>
An LLM is a neural network trained on massive amounts of text that generates language by predicting the most likely next token based on the context it receives.
</br>

---
```text
User Input
     ↓
Convert to Tokens
     ↓
Look at Context
     ↓
Predict Next Token
     ↓
Add Token to Output
     ↓
Repeat Thousands of Times
     ↓
Final Response
```
